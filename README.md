# Nihat — Portfolio

Kişisel projelerimi ve çalışma yaklaşımımı paylaştığım sade, responsive portfolyo sitesi.

## Yapı

- `index.html` — içerik ve proje kartları
- `styles.css` — responsive tasarım ve açık/koyu tema
- `script.js` — tema tercihi, scroll ve görünme animasyonları

`main` geliştirme dalıdır. `release` GitHub Pages üzerinde yayınlanan canlı sürümdür.
