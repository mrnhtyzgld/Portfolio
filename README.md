# Nihat — Portfolio

Seçili makine öğrenmesi ve sistem projelerimi tek ekrana yakın, piksel-art bir arayüzde sergileyen kişisel portfolyo.

## Yapı

- `index.html` — içerik ve proje kartları
- `styles.css` — responsive arayüz ve piksel estetiği
- `script.js` — proje durum göstergesi
- `assets/pixel-workshop.png` — özgün arka plan illüstrasyonu

`main` geliştirme dalıdır. `release` GitHub Pages üzerinde yayınlanan canlı sürümdür.
